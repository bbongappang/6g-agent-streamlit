# 스마트팩토리 작업자 가이드 KB (로컬)

- 진동 급증 + 전류 상승 + 온도 상승은 베어링 마모/정렬 불량/윤활 문제 가능성이 큼.
- 고장 확률이 높으면: 예방정비 티켓 생성 → 감속 운전 → 부하 분산 → 점검 순.
- 안전 리스크(severity 높음)면: 즉시 감속/정지, 작업자 접근 통제, 보호구 착용 확인.
- 센서 데이터가 불확실(변동성↑)하면: 추가 샘플링/주기 단축, 다른 센서(열화상/소음) 교차검증 권장.
- 통신 운영 관점:
  - 안전/제어: URLLC 성격 (저지연/고신뢰)
  - 영상/가시화: eMBB 성격
  - 센서 대량: mMTC 성격
- Selective RIS:
  - Passive는 상시 저비용
  - Active는 불확실성↑/품질 확보 필요 시에만 선택적으로 가동
